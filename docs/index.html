같은 방, 같은 지도

PinLink는 6자리 방 코드 하나로 친구·가족·동료가 같은 방에 들어와 서로의 실시간 위치를 한 지도에서 보는 앱입니다. 공유 시간은 계속 / 1시간 / 3시간 / 8시간 / 24시간 중에 고르고, 언제든 일시정지하거나 방을 나갈 수 있습니다.

  • 멤버별 핀: 닉네임·아바타 색·마지막 갱신·배터리·이동 중/정지
  • 국내는 네이버 지도, 해외는 CARTO 지도 — 이동하면 자동으로 바뀝니다
  • 이동 중에는 속도(km/h), 서 있을 때는 그 자리에 머문 시간을 함께 보여 줍니다
  • 약속 장소(집결 핀)를 지도에서 찍어 방 전체에 공유
  • 방 안 실시간 채팅 — 3초마다 새 메시지, 읽지 않은 메시지는 탭 배지로
  • 앱을 닫아도 공유 — 공유 중에는 알림에서 바로 멈출 수 있어요
  • 한국어 · English · 日本語 · 中文 · Español

무료 · 광고 지원

PinLink는 무료로 제공되며, 화면 최하단의 배너 광고와 방에 들어갈 때의 전면 광고로 운영됩니다 (Google AdMob). 광고는 위치 공유 기능을 막지 않으며, 개인정보 처리방침 8항에 광고 관련 내용을 밝혀 두었습니다.
